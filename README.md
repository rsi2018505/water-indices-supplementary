## Columns
- **S1**: Study Id, Water Index Name, Sensor Platform, Target Application, Validation Method, Key Performance Metric
- **S2**: Study Id, Water Index Formulation, Study Area / Geographic Context, Water Body Type, Key Challenge Addressed
- **S3**: Study Id, Water Index Formulation, Study Area / Geographic Context, Flood/Drought Type, Key Methodological Contribution
- **S4**: Study Id, Water Index Formulation, Study Area / Geographic Context, Vegetation Type, Key Methodological Contribution
- **S5**: Study Id, Water Index Formulation, Study Area / Geographic Context, Coastal Application Type, Key Methodological Contribution

CSV files are UTF-8 and open directly in Excel.
